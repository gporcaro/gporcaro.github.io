Privacy policy

Last updated: 2026-10-04

gp-clone is used by one person (its owner) with the owner's own Google account. No other users are supported.

  • Data accessed: the owner's Gmail messages (read), Gmail drafts (create), and Google Calendar events (read), using the scopes gmail.readonly, gmail.compose and calendar.readonly.
  • Use: only to produce summaries and draft replies for the owner. The app never sends email.
  • Storage: data is processed on the owner's personal computer. OAuth tokens are stored locally and never shared.
  • Sharing: no data is sold or shared with third parties, except the owner's chosen AI model provider to generate summaries on the owner's behalf.
  • Revocation: access can be revoked at any time at https://myaccount.google.com/permissions.

Google user data use complies with the Google API Services User Data Policy, including the Limited Use requirements.
